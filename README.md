# Next Role

An installable web app (PWA) for planning, checking and tracking a move into a secure government, health or research role in Sydney.

- **Plan**: where to look, pay by classification, layoff risk by sector, search method.
- **Titles**: one-tap searches on Seek, LinkedIn, I Work for NSW and APSJobs.
- **Employers**: filterable target list.
- **Check**: an offline, rule-based job ad checker. You can share ads into it from other Android apps.
- **Tracker**: applications, saved on the device, with share, export and import.

Personal details (pay, home area, background) are not in this repo. They live in a profile file that is imported on the phone and stored only there.

Install: open the site in Chrome on Android, then tap **Install app** (or ⋮ → Add to Home screen).
